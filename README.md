# NEX/US — Atlas de Tecnologías Emergentes

Micrositio editorial interactivo en español, inspirado en láminas conceptuales oscuras y diagramas orgánicos.

## Páginas
- `index.html` — presentación visual y mapa de 12 tecnologías.
- `tecnologias.html` — biblioteca de 12 fichas con búsqueda, filtros y modales.
- `laboratorio.html` — laboratorio conceptual de escenarios y 5 sectores.
- `horizontes.html` — escenarios prospectivos, fuentes y glosario.

## Organización
- `assets/styles.css` — sistema de diseño responsive, animaciones y componentes.
- `assets/app.js` — navegación, mapa, filtrado, interacción y laboratorio.
- `assets/data.js` — datos editoriales sobre tecnologías, sectores, glosario y fuentes.
- `assets/favicon.svg` — identidad gráfica.

## Desarrollo local
Sitio estático sin compilación ni dependencias JS externas. Abrir `index.html` en navegador moderno, o servir con `python -m http.server 8000`.

## Publicación
GitHub Pages desde `main` y `/(root)`:
https://yhovelalex-lgtm.github.io/atlas-tecnologias-emergentes/

## Transparencia
- El laboratorio utiliza reglas visuales ilustrativas, no modelos predictivos calibrados.
- La madurez tecnológica se expresa mediante etiquetas editoriales, no mediante TRL certificados.
- La línea temporal 2026–2035 presenta escenarios prospectivos, no fechas de adopción garantizadas.
- Las fuentes externas se citan como lectura de contexto; verificar cifras y conclusiones en las publicaciones originales.
